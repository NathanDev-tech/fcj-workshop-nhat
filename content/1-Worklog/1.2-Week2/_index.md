### Objectives for Week 2:

* Gain an overview of **Cloud Computing** and the **Amazon Web Services (AWS)** platform.
* Become familiar with core AWS services and how AWS organizes its cloud infrastructure.
* Learn the basics of resource management, access control, and security on AWS.
* Understand how to use several common AWS services such as **IAM, EC2, S3, VPC, Load Balancer, Auto Scaling, and CloudFront**.
