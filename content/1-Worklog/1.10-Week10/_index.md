### Week 10 Objectives:

- Understand AWS CDK and its relationship with CloudFormation.
- Practice defining AWS infrastructure as code with CDK.
- Learn how CDK Advanced organizes architectures containing multiple AWS services.
- Get started with Amazon Bedrock, foundation models, prompts and inference.
- Strengthen understanding of IAM Users, IAM Groups, IAM Policies and IAM Roles.
- Learn about Assume Role, trust policies and using Conditions to control access.
- Connect Infrastructure as Code, Generative AI and IAM Security concepts in an AWS environment.
